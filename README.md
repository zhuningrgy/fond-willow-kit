# fond-willow-kit

Open-source maintainer · Rust and cargo

拿来练手的小仓库

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/fond-willow-kit.git
cd fond-willow-kit
cargo build --release
```
